Copyright (c) 2025-2026 [Antmicro](https://www.antmicro.com)

## Introduction

Renode WS-API is a typescript library for connecting and communicating with Renode via `--server-mode`.

## Installation

The recommended way to install ws-api is to use this git repository link and pin to a version using a tag.

## Development

### Run checks

```bash
pnpm check
```

### Compile

```bash
pnpm compile
```

### Fix formatting

```bash
pnpm fix
```
